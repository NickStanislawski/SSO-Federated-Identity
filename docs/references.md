# Protocol and library references


## Primary references checked on 2026-10-12

- [Authlib Flask integration](https://docs.authlib.org/en/latest/oauth2/client/web/flask.html): automatic OIDC ID-token parsing and client integration.
- [Authlib HTTP clients](https://docs.authlib.org/en/stable/oauth2/client/http/index.html): PKCE client behavior.
- [SignXML documentation](https://xml-security.github.io/signxml/): pinned certificates, expected signature location, and consuming the verified signed element.
- [Okta Python redirect guide](https://developer.okta.com/docs/guides/sign-into-web-app-redirect/python/main/): web app registration and development tenant prerequisites.

UI labels and tenant features can change. Review the current provider documentation before making tenant changes. The local SAML profile is deliberately restricted and is not a general-purpose production toolkit.
